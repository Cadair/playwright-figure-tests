playwright_figure_tests
=======================

A pytest helper library for running visual regression tests against rendered web pages using Playwright, built on top of pytest-mpl_.

This package is designed to use the excellent pytest-mpl, particularly the `hybrid comparison mode <https://pytest-mpl.readthedocs.io/en/stable/hybrid_mode.html>`__, but for screenshots generated by playwright.
The hybrid mode of pytest-mpl is a workflow used in a number of places for ease of reviewing and approving changes to figure tests, it has also been used by `glue-jupyter <https://github.com/glue-viz/glue-jupyter/>`__ with playwright generated screenshots, which is where this idea originated.

.. _pytest-mpl: https://github.com/matplotlib/pytest-mpl
